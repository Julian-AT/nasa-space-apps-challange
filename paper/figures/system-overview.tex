\caption{System overview as designed; this paper does not verify its deployment. The offline Python stages \texttt{terraluna\_pipeline} and \texttt{terraluna\_ml} write one versioned, checksummed release bundle, which is the only interface between them and the web. The bundle is meant to be published to object storage and a content delivery network, from which Next.js 16 on Vercel reads it. No Python runs in the request path. The visitor's browser shows maps and runs the live probe in a Web Worker, which reads Copernicus GLO-30 cloud optimized GeoTIFF ranges directly or through the \texttt{/api/v1/dem} proxy. Solid arrows show data flow. Dashed outlines mark components that are not done: the Hugging Face Hub mirror (cut: its publication is a human checkpoint that did not happen) and the React Three Fiber twins (cut).}
