## Codebase Patterns
- Build Mac, checked 2026-11-14: uv 0.9.26; Python 3.12.13 via uv; Node 22.23.3 (nvm); pnpm 12.16.1; jq 1.8.2; GNU Make 3.81; actionlint installed.
- `python3` on PATH is Anaconda's 3.14. Always use `uv run`, never bare `python3`.
- GNU Make 3.81: no .ONESHELL, no grouped targets (`&:`), no `!=` assignment. Keep recipes POSIX sh.
- No system GDAL (`gdalinfo` is missing). GDAL comes from the rasterio wheel.
- macOS has no coreutils `timeout`.
- Other workers may share this repository. Stage explicit paths only.
- Commits: commitlint (config-conventional, scopes lower case such as t0-01) runs from the husky commit-msg hook (core.hooksPath=.husky/_). The root package.json already exists for this; T0-04 extends it.
- ralph.sh commits review files, gate results, loop notes and compact logs (logs/agents/<date>/*.jsonl). Full transcripts are in git-ignored logs/agents/<date>/raw/.
- ralph.sh matches story `files` with bash `[[ $p == $glob ]]`, so `*` also matches `/`: `pipeline/*` covers nested paths.
- Context7 works over plain HTTP via WebFetch: https://context7.com/api/v1/<org>/<repo>?topic=<words>&tokens=<n>. For flags of an installed CLI, `<cli> --help` is authoritative.
- The uv workspace root is virtual (no [project]). A plain `uv sync --locked` there installs both members and the dev group (checked on a fresh copy).
- Bundle records live in pipeline/src/terraluna_pipeline/schema.py. Base `Record` uses extra=forbid, strict=True, frozen=True and regex_engine="rust-regex". Constraints are kept to what JSON Schema can express (patterns, enums, minLength, minimum), so T0-03/T0-04 can stay in parity.
- Parity traps for T0-03 (both checked with jsonschema 4.26.0): (1) the Python `jsonschema` package matches `pattern` with `re.search`, where `$` also matches before a trailing newline, so "<64 hex>\n" passes `^[0-9a-f]{64}$` there but fails pydantic (rust-regex) and ECMA/zod. (2) pydantic strict rejects JSON `1.0` for an int, while JSON Schema `integer` accepts it and JS cannot tell 1.0 from 1.
- mypy --strict reports a tuple of lambdas that are called later as no-untyped-call. Call the functions directly.
- `mktemp` + `mv` leaves a file with mode 600. Run `chmod 644` after a jq rewrite of prd.json. `jq .` reproduces prd.json's formatting byte for byte.
- The Codex reviewer runs in a read-only sandbox, so it marks every check command NOT_RUN. Only the Claude reviewer and the gate run commands. To show that a resolution edit changed only resolution fields, compare the hash of `jq 'del(.findings[].resolution)'` before and after.
- paper/scripts/ is a package (scripts/__init__.py): a top-level numbers.py would shadow the standard library `numbers` module, which mypy refuses and which pydantic/_decimal import. Tests import `scripts.<name>`. Run scripts with `python -P` (the Makefile does). numbers.py exits if `sys.flags.safe_path` is false.
- make -C paper runs pytest with the repository root as rootdir, so the root pyproject's pytest options (--strict-config, -ra) apply. ruff and mypy use paper/ruff.toml and paper/mypy.ini, passed explicitly.
- Tectonic 0.17.0 caches in ~/Library/Caches/TectonicProject.Tectonic and reruns TeX by itself when aux/out files change. It exits 0 on undefined citations and on BibTeX errors. TeX log lines wrap at 79 characters, so match the opening words of a message. A \bibliography with no \cite gives "I found no \citation commands---while reading file main.aux" and "(There was 1 error message)" in main.blg.
- zsh traps: `for c in "make -C paper x"; do $c; done` does not word-split (exit 127); use `sh -c "$c"`. `echo ===` fails (`==` expansion); use `echo ---`.
- To test against another branch's unmerged work without merging or switching: `git archive HEAD | tar -x -C $tmp`, then `git archive <branch> <paths> | tar -x -C $tmp`, then `uv sync --locked` and the checks inside $tmp. The uv cache makes the sync fast and offline; Tectonic's cache is shared.
- ralph/t0-bootstrap was merged into ralph/t16-paper at c2eac70, so terraluna_pipeline.export and fixtures/mock-bundle are present. Run `uv sync --locked` after any merge that touches pyproject.toml or uv.lock, before the paper checks.
- A paper script that imports a sibling module (`from scripts.tex_prose import ...`) cannot run as `python -P scripts/x.py`: -P keeps both scripts/ and the working directory off sys.path. The Makefile runs such scripts as `PYTHONPATH=. uv run --frozen python -P -m scripts.<name>` from paper/ (variable PYTHON_MODULE). PYTHONPATH is still honoured under -P.
- paper/scripts/tex_prose.py is the one LaTeX reader for paper checks: `extract(text)` gives `code` (comments, verbatim, math, key-command arguments and TikZ blanked, same length as the source), `prose` (markup removed) and `comments` by line. Both keep every line break, so `line_at(view, offset)` is the source line. Reuse it for any new manuscript check instead of another regex stripper.
- tex_prose.py reads the gap before an argument as TeX does (`space_end`: spaces, comments, single line breaks; a blank line is \par) and locates every non-prose argument in pass 1, where comments are still visible: key-command arguments, \begin/\end names, environment layout arguments and the [length] of \\. Pass 2 only drops command names and braces. A regex over the code view must allow any white space between \begin or \end and its brace, because a blanked comment line looks blank there: build it with `environment_boundary()`. hyperref's \url makes % and the end of a line active before it reads its argument; \href reads its { first.
- The Tectonic cache holds the pinned bundle's package sources (~/Library/Caches/TectonicProject.Tectonic/bundles/data/<digest>/, e.g. hyperref.sty), so you can check what a LaTeX command really does offline with grep.
- tex_prose.py pass 2 joins adjacent groups as TeX prints them ({seam}{less} is one word). Only two arguments of one command are separate words: `_CodeScanner.argument_breaks` counts them with `argument_count()` (TEXT_COMMANDS, accents, begin/end 1; NO_ARGUMENT_COMMANDS 0; key commands their keys plus TEXT_ARGUMENTS_AFTER_KEYS; unknown commands every following group). When you add a command to one of those tables, check its argument count too.
- ruff RUF001 rejects literal en dashes, minus signs, fullwidth question marks and similar characters in strings. Write them as \u escapes, and check new files with `grep -nP '[^\x00-\x7f]'`, because a file written with escapes in the editor can still end up holding the literal characters.
- tex_prose.py drops what TeX prints nothing for. `_CodeScanner.unprinted(code)` collects the offsets: the spaces, comments and one line break after a control word or before an accent letter (space_end on the source), each comment with its line break and the next line's indent, and the span of each key command in UNPRINTED_KEY_COMMANDS. Pass 2 drops them, and `_ProseWriter` holds a skipped line break until the word ends. The prose keeps the source's line count, and a word joined across lines sits on the line where it starts. When you add a key command, decide whether it prints anything (UNPRINTED_KEY_COMMANDS). When you add a command with no argument, decide whether it prints nothing (DECLARATIONS, PRINTS_NO_TEXT).
- Report a prose finding with `Source.prose_line(offset)`, never `line_at(prose, offset)`: a held line break follows its joined word, so text after it can sit on the line before in the prose (Text.% then robust gives Text.robust). overlap_check.located_tokens() gives tokens with their source lines. `line_at` stays right for the code view.
- Search the code view for a command with `tex_prose.find_commands(pattern, code)`, not `pattern.finditer(code)`: a regex also matches after the first backslash of an escape pair (\\begin{tabular} is a line break and text). The pattern must start with a backslash.
- When a key command has text arguments (TEXT_ARGUMENTS_AFTER_KEYS), the gap before each one prints nothing (drop_text_argument_gaps); options before the text are dropped only for OPTIONS_BEFORE_TEXT, because \href and \textcolor read a [ there as their text.
- Abstracts (fold_latex) and the prose of .tex files (pass 2) fold accents and special letters through one helper, `tex_prose._letter_at`, with ACCENT_GAP (spaces and at most one line break) wherever TeX skips it, and fold_latex reads left to right as pass 2 does. Change accent reading there only, and keep `located_tokens(extract(t))[0] == tokens(t)` for accent-only text (test_accents_tokenise_alike_in_prose_and_abstracts). A pass 2 match that spans a line break must hold it (`_write_letter`), or the prose loses a line.
- A starred command's * may follow a gap: TeX skips the spaces after a control word, and LaTeX's \@ifstar finds the * through \@ifnextchar, which skips space tokens (latex.ltx:1602-1621 in bundle v33). Read the star of \\ and of STARRED_KEY_COMMANDS with `_CodeScanner.star_end` (space_end before the *), never `text.startswith("*", i)`. Only commands that bundle v33 defines with \@ifstar are in STARRED_KEY_COMMANDS; any other command reads a * as its argument (seam\label *less prints seamless; natbib's \citeyear *{b} cites the key * and prints b). When you add a key command, check whether it has a starred form (`tectonic -X bundle cat <pkg>.sty | grep ifstar`). Pass 2 and argument_breaks still drop only an adjacent *, which is harmless: a * is neither a token nor a lint trigger.
- A command reads only the optional [..] arguments it defines, where it defines them: tex_prose.KEY_OPTIONS (one count per key), key_options() for the \cite family (two, none for \citenum and \citetext), ENVIRONMENT_ARGUMENTS (one count per layout argument), one for floats, and TEXT_OPTIONS before a text argument. Any other [ is the argument, as TeX reads any one token (\label[x]{} prints x]). When you add a key command or an environment, look up its options in bundle v33 (`tectonic -X bundle cat <pkg>.sty`, follow \@ifnextchar[ and \@testopt) and pass optional_arguments_end an explicit limit.
