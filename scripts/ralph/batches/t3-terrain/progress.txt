## Codebase Patterns
- Build Mac, checked 2026-11-14: uv 0.9.26; Python 3.12.13 via uv; Node 22.23.3 (nvm); pnpm 12.16.1; jq 1.8.2; GNU Make 3.81; actionlint installed.
- `python3` on PATH is Anaconda's 3.14. Always use `uv run`, never bare `python3`.
- GNU Make 3.81: no .ONESHELL, no grouped targets (`&:`), no `!=` assignment. Keep recipes POSIX sh.
- No system GDAL (`gdalinfo` is missing). GDAL comes from the rasterio wheel.
- macOS has no coreutils `timeout`.
- Other workers may share this repository. Stage explicit paths only.
- Commits: commitlint (config-conventional, scopes lower case such as t0-01) runs from the husky commit-msg hook (core.hooksPath=.husky/_). The root package.json already exists for this; T0-04 extends it.
- ralph.sh commits review files, gate results, loop notes and compact logs (logs/agents/<date>/*.jsonl). Full transcripts are in git-ignored logs/agents/<date>/raw/.
- ralph.sh matches story `files` with bash `[[ $p == $glob ]]`, so `*` also matches `/`: `pipeline/*` covers nested paths.
- Context7 works over plain HTTP via WebFetch: https://context7.com/api/v1/<org>/<repo>?topic=<words>&tokens=<n>. For flags of an installed CLI, `<cli> --help` is authoritative.
- The uv workspace root is virtual (no [project]). A plain `uv sync --locked` there installs both members and the dev group (checked on a fresh copy).
- Bundle records live in pipeline/src/terraluna_pipeline/schema.py. Base `Record` uses extra=forbid, strict=True, frozen=True and regex_engine="rust-regex". Constraints are kept to what JSON Schema can express (patterns, enums, minLength, minimum), so T0-03/T0-04 can stay in parity.
- Parity traps for T0-03 (both checked with jsonschema 4.26.0): (1) the Python `jsonschema` package matches `pattern` with `re.search`, where `$` also matches before a trailing newline, so "<64 hex>\n" passes `^[0-9a-f]{64}$` there but fails pydantic (rust-regex) and ECMA/zod. (2) pydantic strict rejects JSON `1.0` for an int, while JSON Schema `integer` accepts it and JS cannot tell 1.0 from 1.
- mypy --strict reports a tuple of lambdas that are called later as no-untyped-call. Call the functions directly.
- `mktemp` + `mv` leaves a file with mode 600. Run `chmod 644` after a jq rewrite of prd.json. `jq .` reproduces prd.json's formatting byte for byte.
- Run settings come only from `terraluna_pipeline.config`: `load_terrain_config()` returns a frozen TerrainConfig (lengths as float metres), and `load_run_config().value("targets.mars.0.primary_window_id")` returns any other entry unchanged, with nulls as None. Radii come from `terraluna_pipeline.geometry.body_radius_m` / `BODY_RADII_M` (keys moon, mars, earth, exact match).
- PyYAML 6.0.3 follows YAML 1.1: `1e3` and `1.0e3` load as strings (`1.0e+3` is a float), `none` is a string, and a duplicate key silently keeps the last value. The config loader rejects duplicates and wrong types.
- A workspace member may have its own `[dependency-groups].dev`; the virtual root's `uv sync --locked` installs it. types-pyyaml lives in pipeline/pyproject.toml's dev group for that reason.
- mypy (strict, warn_unreachable) narrows `x in TUPLE_OF_LITERALS` to the Literal type, so a later `cast` is flagged redundant. Comparing a `tuple[float, ...]` with an int-tuple literal makes mypy mark the next line unreachable; write float literals.
- zsh treats a bare `=====` argument as `=` expansion and fails; quote separators in shell commands.
- A permission rule blocks `sed` on PRD.md. Find headings with `grep -n '^#' PRD.md`, then read the range with the Read tool (offset/limit).
- Review files (reviews/*.json) are `jq .` formatted: edit a resolution with jq and prove nothing else changed by diffing `jq 'del(.findings[].resolution)'` against `git show HEAD:<file>`.
- Window geometry lives in `terraluna_pipeline.geometry`: `window_grid(width_m, spacing_m)` returns a read-only WindowGrid (size = largest n with n*D <= W, 55 at 5000/90; `mesh_m()` is indexed [row, column], row 0 at the top), and `aeqd_inverse(x, y, *, lat0_rad, lon0_rad, radius_m)` / `aeqd_forward(lat, lon, *, ...)` work in radians with longitudes in [-pi, pi). Pass radii from `body_radius_m`.
- Float64 floor for positions: a longitude near +-pi is resolved only to 2.2e-16 rad (1.4e-9 m on the Earth sphere). Compare window coordinates normalised by W (PRD 7 "normalized fixtures"), not in plain metres with atol 1e-12.
- For a high-precision reference in a scratch script, `uv run --with mpmath python ...` adds mpmath to a throwaway environment without touching pyproject or uv.lock.
- To stress a Hypothesis test that already has @settings, wrap `test.hypothesis.inner_test` in a fresh `given(...)` plus `settings(max_examples=..., database=None)`; re-decorating the test itself raises InvalidArgument.
- `pytestmark = pytest.mark.filterwarnings("error")` turns numpy RuntimeWarnings (divide by zero, invalid value) into failures, which catches hidden NaN paths.
- PRD 7 tolerances on window coordinates are applied in plain metres (T3-02 round 1), never normalised by W. On the Earth sphere at the 25 m grid offsets, that is under two ulps of a latitude. Evaluate small increments and add them last to phi0/lam0 (see `geometry.aeqd_inverse` and `aeqd_forward`), and test at D29 pixel centres: closer than about 14 m to the centre, float64 cannot meet atol 1e-12 m.
- mpmath 1.4.1 is a pipeline dev dependency for exact test references (`mpmath.workdps(40)`; `mpf(float)` is exact). It has no py.typed, so import it with `# type: ignore[import-untyped]` and convert results with float(). It costs about 0.1 ms per point, so check a subsample of large grids.
- To run tests against a mutant without touching the repo, copy pipeline/src/terraluna_pipeline to /tmp/x/pipeline/src/ and config/run.yaml to /tmp/x/config/, then run `PYTHONPATH=/tmp/x/pipeline/src uv run pytest ...`. `config.DEFAULT_RUN_CONFIG` is parents[3] of config.py.
- To show that a tolerance cannot be met in float64, rather than missed by the code, push every float64 (lat, lon) within a few ulps of the 40-digit exact inverse (`math.nextafter`) through an exact forward. Then compare the module's failures with the cases where even the best pair fails (T3-02 round 2). Reviewers treat a narrowed test domain as weakening until a human amends the contract, so escalate rather than narrow. The earlier pattern line suggesting x/W normalisation is superseded: tolerances are in plain metres.
- Exact AEQD references for tests live in pipeline/tests/test_geometry_aeqd.py: `exact_inverse` and `exact_forward` (40-digit mpmath, centre frame turned by -lon0) and the mp-level `exact_point_mp` / `exact_offset_mp`, which invert each other to 1e-25 m. Compare longitudes with `assert_angles_close`, which picks the 2 * math.pi representative nearest the reference.
- A Hypothesis `@example` stores its examples on the raw function, so wrapping `test.hypothesis.inner_test` in a new `given` still replays them. For a random-only stress, copy the function first: `types.FunctionType(fn.__code__, fn.__globals__, fn.__name__, fn.__defaults__, fn.__closure__)`.
- For scratch mutants built with `git archive <rev>`, check `terraluna_pipeline.geometry.__file__` under PYTHONPATH first. A wrong directory silently falls back to the editable install. (`echo $rev | tr -c 'a-z0-9' '_'` also turns the trailing newline into `_`.)
- Near a pole, AEQD window coordinates near 0 are differences of terms the size of the distance to the pole (up to 2.5 km). Plain float64 libm evaluation then misses PRD 7's 1e-12 m. `geometry.aeqd_forward` uses double-double helpers (`_two_sum`, `_two_prod`, `_dd_mul`) and series in the exact colatitude ((pi/2 - |lat|) + 6.123233995736766e-17). Random Hypothesis draws almost never land in pole windows: scan |lat0| within 3.6 km of a pole explicitly.
- Longitudes are real angles on the true sphere (T3-02 round 3, codex2-r3-1). A turn is 2 * math.pi plus `geometry._TWO_PI_LO` = 2.4492935982947064e-16, carried in the low part of a double-double. Exact references take each float64 longitude at its exact value with mpmath's pi and never undo a 2 * math.pi wrap; that hid a 1.6e-9 m error on Earth. This supersedes the round-1 learning "a true-sphere reference must undo the inverse's wrap first". [-math.pi, math.pi) falls 2.4e-16 rad short of a turn, so the inverse picks the nearer of -math.pi and nextafter(math.pi, 0) in that gap.
- Pixel centres of random grids (any width <= 5000 m and spacing) are continuous offsets. In about 2% of such grids, no float64 point round-trips a pixel within PRD 7's metre tolerance: components <= 13 m, or y = 0 exactly on whole-cell grids. Grids whose components are all >= 25 m pass (0 of 12,000). The D29 grids are the 5000/90 analysis grid and the 64 x 78.125 m encoder grid (`ml.input_px`, `ml.input_m_per_px` via `load_run_config().value`).
- In a scratch stress script, `test.hypothesis._given_kwargs` (private API, Hypothesis 6.170) returns a test's strategies for re-wrapping with `given(**kwargs)`. For a composite strategy argument, an `@example` passes the drawn value itself, for example `grid_pixels=("encoder", [(31, 32)])`.
- Source lookups and the D29 resampler live in `terraluna_pipeline.geometry` (T3-03): `GeographicLookup`, `PolarStereographicLookup` and `EquirectangularLookup` (frozen, keyword-only, no defaults, angles of product parameters in degrees) each have `project` / `unproject` (radians to projected degrees or metres and back), `pixel_from_projected` / `projected_from_pixel` (false offsets and the north-up GDAL geotransform, origin at the outer corner of pixel (0, 0)) and `to_pixel` / `from_pixel`. Pixel coordinates are pixel-centre indices. `bilinear_resample(source, column, row, *, nodata)` and `resample_window(source, lookup, *, grid, body, lat0_rad, lon0_rad, nodata)` return a read-only `ResampledGrid(values, valid, inside)` with NaN wherever `valid` is False. `nodata` is required (None when the product declares none).
- A 40-digit mpmath reference is not exact for sums of float64 values of very different exponents: `mp(-360) + mp(-4e-230)` rounds to -360 and flips a wrap. For affine references and wrap decisions, use `mpmath.fadd/fsub/fmul(..., exact=True)`. Near the opposite pole of a stereographic projection, 1 + sin(phi) cancels to 1e-32, so that reference runs at 100 digits.
- The Hypothesis example database (`.hypothesis/`, git-ignored) is shared by every pytest run in the worktree, including scratch mutant runs under PYTHONPATH. Examples a mutant finds are replayed against the real code in the next normal run. That surfaced a real defect in T3-03, so when a run fails after mutant runs, read the example before blaming the mutants.
- A decision taken from a quotient such as floor(d / 360) can be off by one, through rounding or through underflow to -0.0 for subnormal d. Settle it with the sign of the exact remainder (two-sum), as in `GeographicLookup.pixel_from_projected`.
- In scratch stress scripts, `np.seterr(all="raise")` also raises on harmless underflow of subnormal inputs. numpy ignores underflow by default and pytest's warning filter never sees it, so use `np.seterr(divide="raise", over="raise", invalid="raise")`.
- `np.asarray` silently drops a numpy masked array's mask (rasterio `read(masked=True)` returns one). Any function that takes raster data must read `np.ma.getmaskarray` before `np.ma.getdata`, as `geometry.bilinear_resample` does (T3-03 round 1).
- Compare a declared nodata sentinel in the raster's storage type, never after float64 promotion: a float32 band stores -9999.1 as -9999.099609375, and int64/uint64 neighbours of a sentinel beyond 2**53 merge in float64. GDAL's mask band casts the double nodata to the band type (gcore/gdalnodatamaskband.cpp) and adds a ~4.8e-7 relative tolerance for floats (ARE_REAL_EQUAL, gcore/gdal_cpp_functions.h); Terraluna matches exactly (`geometry._sentinel_pixels`).
- In zsh here, `grep` is ugrep: a pattern starting with `-` needs `grep -e` or `--`.
- numpy 2.5 casts a float64 to float16/float32 rounding to nearest, ties to even: values less than half an ulp beyond the largest finite value become that value, and from the half-ulp tie on they become inf, with `RuntimeWarning: overflow encountered in cast` (a test failure under filterwarnings("error")). Wrap such casts in `np.errstate(over="ignore", under="ignore")` and test the result with np.isfinite. Underflow to 0 emits no warning.
- Python's `struct.pack('<e' | '<f', x)` is a correctly rounded float16/float32 conversion that does not go through numpy. It raises OverflowError where the value would round to inf, so it serves as an independent reference for storage-type rounding.
